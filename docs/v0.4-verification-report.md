# Lumiverse Toolkit v0.4 Verification Report

Version: `0.4.0+codex.20260906063321`

## Release scope

v0.4 adds the shared Creative Quality Kernel, normalized agency and source
authority, artifact ownership, a Lumiverse capability map, capability receipts,
and a resumable build ledger. All six specialists route through these contracts.

Character Forge gains a behavioral-model, greeting-lab, distance-test, and World
Book candidate pass. Scenario Forge uses dynamic sections by mode. Lorebook
Forge chooses activation architecture from project needs and blocks silent
reduced-fidelity embedding. World Forge distinguishes arc, sandbox, and hybrid
packages while keeping preset creation separate. Project Steward merges
evidence without promoting uncertainty into success.

## Evidence model

Deterministic activation checks report **PASS, FAIL, and UNPROVEN**. Vector
similarity, probability, weighted groups, sticky/cooldown/delay timing, live
imports, and model behavior remain UNPROVEN until supported by matching runtime
evidence. Passing this repository's static suite is **not runtime certification**.

The embedded Character Book compiler preserves the supported observed V3 subset.
If advanced settings cannot be represented, compilation stops unless the user
explicitly selects reduced fidelity; the omission manifest remains mandatory.

## Intentionally deferred

- Full Idea Lab implementation and source/wiki batch ingestion.
