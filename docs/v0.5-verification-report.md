# Lumiverse Toolkit v0.5 Verification Report

Version: `0.5.0+codex.20260906074039`

## Implemented capabilities

The shared `lumiverse-toolkit.idea-lab/v1` record supports direct drafting,
optional interview, divergent variants, anti-generic revision, and influence
combination. Validation checks candidate identity, direction signatures,
meaningful divergence, complete comparison, selection, canon status, and agency
blockers.

The shared `lumiverse-toolkit.source-ledger/v1` record supports mixed source
inventories, authority and relevance decisions, content aliases, stable entity
IDs, provenance-bearing facts, temporal snapshots, public/character/rumor/GM
knowledge partitions, source conflicts, adaptation choices, and grounded
artifact or World Book suggestions.

The source validator blocks active future-knowledge and hidden-truth ownership
leaks, unresolved conflicts in final ledgers, missing provenance, duplicate
source content without an alias, dangling entities, and ungrounded suggestions.

## Specialist integration

- Character Forge consumes timeframe-valid facts and knowledge partitions.
- Scenario Forge treats future-knowledge leakage as a blocker.
- Lorebook Forge begins sourced work from grounded entry suggestions and spoiler
  intent.
- World Forge separates Databank-scale source corpora from playable World Book
  facts.
- Project Steward validates both shared records and owns conflicts/adaptations.
- Preset Converter uses source ledgers only as migration evidence.

## Evidence boundaries

No bundled crawler bypasses access controls, authentication, rate limits, or
robots policy. The toolkit requests a supplied export or excerpt when access is
unavailable and material.

The validators establish record consistency; this is **not factual certification**
of a wiki, interpretation of a long work, copyright status, or live Lumiverse
behavior. Source accuracy and runtime activation require their own evidence.
