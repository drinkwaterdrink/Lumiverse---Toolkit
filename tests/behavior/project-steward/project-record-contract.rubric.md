# Expected Behavior Rubric: Project Record Contract

Score each item 0 or 1.

1. Uses a stable `project_id`, project name, and project version.
2. Records Lumiverse as target plus a documentation/source-version field rather than claiming an unverified product version.
3. Records enabled/planned artifact types separately from artifacts that already exist.
4. Encodes source authority: user canon above approved project sources above generated/external suggestions.
5. Uses explicit fact statuses including at least canon and provisional.
6. Encodes the complete agency contract without weakening it to a generic “respect agency” sentence.
7. Records rich-detail preference separately from token-economy/always-injected constraints.
8. Records Android/mobile as a project requirement.
9. Scopes Real Frank naming, +0.1 versioning, bundled regex, and settings preservation to Real Frank rather than every preset.
10. Records the generic roleplay preset as tracker-agnostic and the SimTracker preset as optional/unselected.
11. Creates planned artifact records with stable IDs, types, status, and dependencies/ownership where known.
12. Includes a dependency-edge model or dependency records suitable for later propagation.
13. Includes an empty canon ledger, entity index, validation ledger, and release state ready for future additions.
14. Distinguishes user-provided values from generated defaults/proposals.
15. Does not invent character, world, scenario, or tracker canon.
16. Produces a machine-reusable structured record rather than only prose guidance.
17. Does not present an invented `lumiverse.project-record` schema identifier or version as established; without a supplied contract it must label the shape as a proposal.

Baseline failure threshold: fewer than 15 points or any failure of items 4, 6, 9, 10, 15, 16, or 17.
