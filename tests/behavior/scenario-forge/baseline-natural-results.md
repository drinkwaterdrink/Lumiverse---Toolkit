The explicit contract prompt was retained as a regression case because it gave the baseline the answer: agents followed the named sections and pressure-graph checklist well.

The meaningful RED test used `natural-sandbox.prompt.md`, which asked naturally for a rich, open Lumiverse scenario without naming the toolkit template. Five fresh agents received only that prompt.

## Behavior already strong

The natural baseline created vivid grounded ensembles, plausible private pressures, agency-safe openings, modular scene ideas, and restrained supernatural ambiguity. Scenario Forge should preserve those strengths rather than prescribe plot content.

## Skill requirement derived from RED

The missing behavior is automatic workflow structure when the user does not know how to request it:

- canonical CORE/USER/NPC/CONFLICT/OPENING/EXPANSION output;
- a complete pressure graph with entry conditions, concealed information, state effects, and recombination;
- explicit provisional status for generated story additions;
- conditional clocks and continuity state;
- a consistent finalization marker;
- mode behavior that scales density without dropping the core contract.
